# 🎮 Rock Paper Scissors Game

## 📌 Project Overview

This is a simple and interactive **Rock Paper Scissors Game** built using **HTML, CSS, and JavaScript**. The user plays against the computer, and the game runs for **5 rounds**. The player with the highest score at the end is declared the final winner.

---

## 🚀 Features

* 👤 User vs 💻 Computer gameplay
* 🎯 Fixed **5 rounds per game**
* 📊 Displays result after each round
* 🏆 Shows **final winner** after all rounds
* 🔁 **Play Again** button to restart the game
* ⚡ Clean and responsive UI

---

## 🧠 Game Logic

* User selects: **Rock / Paper / Scissors**
* Computer generates a random choice
* Each round result is calculated using:

  * Rock beats Scissors
  * Scissors beats Paper
  * Paper beats Rock
* Scores are updated after each round
* After 5 rounds, the player with the highest score wins

---

## 🎮 How to Play

1. Open the game in browser
2. Click on Rock, Paper, or Scissors
3. Computer will automatically choose
4. Round result will be displayed instantly
5. Continue playing until 5 rounds are completed
6. Final result will be shown
7. Click **Play Again** to restart
